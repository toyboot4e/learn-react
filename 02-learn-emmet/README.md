# Emmet Dojo

## Project setup

I'm using [`volta`] for installing [`node`] and [`npm`]. `node` and `npm` in the `PATH` are automatically updated if the shell integration is set up.

This project was generated with [`vite`]: `npm create vite`. Scripts defined in `package.json` can be run with `npm run <script name>`. Some scripts including `doc` were added manuaally.
